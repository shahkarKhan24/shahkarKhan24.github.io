Agents · RAG↗

Local RAG agent with tools and memory

Fully local tool‑calling agent on LangGraph + Ollama. Answers over PDFs via Chroma, delegates exact arithmetic to tools, and keeps a fixed‑size sliding‑window memory across restarts. Tools are picked purely by matching queries to docstrings — no routing code, no cloud, no API keys.

LangGraphOllamaChromaPython
Interpretability · Safety↗

Refusal‑direction interpretability for LLM safety

Locates, measures and reinforces the internal "refusal" direction of Qwen2.5‑1.5B‑Instruct via difference‑in‑means over residual‑stream activations. Stress‑tests it with directional ablation and hardens it with activation addition — reproducing and extending Arditi et al. (2024).

PyTorchQwen2.5Mech interp
